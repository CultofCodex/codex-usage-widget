# Changelog

All notable changes to Codex Usage Widget will be recorded here.

## 1.0.0 — 2026-09-23

Initial public release.

- Always-on-top vertical usage display for Windows.
- Weekly allowance, reset time, and credit balance.
- Recent-draw total, age, and peak credits-per-minute rate.
- Colour-coded 60-minute activity graph.
- Adaptive refresh during active usage.
- Background CSV usage logging for later analysis.
- System-tray controls and optional launch at Windows sign-in.
- Explicit Launch with Windows On/Off status that refreshes whenever the menu opens.
